# 路线图

[English](roadmap.en.md) | 中文

当前 V2 由 M7 启动；机读状态与 issue 依赖以 [.agents/flow/roadmap.md](../.agents/flow/roadmap.md) 为准。

## M1 工程骨架与质量门禁

交付 FastAPI、Vue 3、双方言数据基座、OpenAPI、鉴权、任务/SSE 与 CI 元门禁。

## M2 轨迹数据与归一化

接入 fixtures、本地轨迹、JSONL 归一化、Agent 树、幂等重放、查询 API 与调度。

## M3 会话浏览与执行流

交付会话列表、概览、Agent 执行流图、深链与性能预算。

## M4 问题与归因

接入外部只读 bad case/probe、问题 API、问题卡与错误详情。

## M5 自进化闭环

交付对象配置、运行、向导、六步状态、事件、git candidate 与占位 patch/评测。

## M6 真实接入与兑现

接入真实上游轨迹、外部契约、patch 评测与聚类升级。

## M7 身份与空间边界

建立唯一管理员、空间角色、AuthProvider 接缝、空间路由与管理界面。

## M8 空间数据面与总览

打通凭据上报、额度、最新 10 个 Session、总览聚合与详情下钻。

## M9 Session 证据与对象版本

归一化关系、完成状态、对象 revision、触发坐标以及 Skill、Agent、知识库文档证据。

## M10 归因管线与七步自进化

交付潜在匹配、归因缓存、候选、四步向导和七步运行详情。

## M11 多归因体验与 V2 切换

交付多归因详情、对象总览、跨栈验收与兼容退役计划。

## M12 真实接入与算法兑现

兑现真实上游、外部契约、patch/评测、聚类升级与平台质量欠账。
