# 指标定义

[English](metrics.en.md) | 中文

## 主指标

每次实验必须指定一个主指标，默认使用任务成功率：

- **Task success rate**：通过评分器的任务数 / 总任务数。
- **Pass@k**：k 次独立尝试中至少成功一次的任务比例，适合高方差任务。

## 护栏指标

- **回归数**：baseline 通过、treatment 失败的任务数量。
- **步数与工具调用数**：衡量流程是否变得冗长。
- **Token 与费用**：单任务平均消耗及总预算。
- **时延**：端到端耗时与关键阶段耗时。
- **人工介入率**：需要人工纠偏或审批的次数。
- **稳定性**：跨随机种子或重复运行的结果方差。

## 记录要求

每次运行至少记录：

- harness 版本与配置哈希
- 任务集版本
- 模型与推理参数
- 随机种子
- 开始与结束时间
- 逐任务结果和完整轨迹
- 汇总指标与异常说明

指标定义变更时，应新建版本并在实验记录中引用，避免不同批次的结果被直接比较。
