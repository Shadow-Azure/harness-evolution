# 事故复盘

[English](README.en.md) | 中文

`docs/postmortem/` 是全库唯一允许叙事的历史层级：记录已发生的故障、影响、根因、处置与防复发动作。编号文件名 `yyyy-mm-dd-主题.md` 按目录浏览，不进文档地图。

## 结构

每篇复盘按顺序包含：

1. **影响**：谁受影响、持续多久、数据是否丢失。
2. **时间线**：发现、止血、恢复、复盘的关键时刻。
3. **根因**：直接触发与系统性条件分开写。
4. **处置**：已完成的修复与验证。
5. **防复发**：可机械校验的门禁或流程改动，注明归属 issue。

## 规则

- 只写已发生的事实，不写推测；不确定处显式标注。
- 不指责个人，聚焦系统条件与可改进的接口。
- 防复发动作必须落成代码、门禁或流程条目，不能只写"加强注意"。
- 复盘与决策理由分开：系统性取舍进 Agent Note，事故叙事留在这里。
