# Roadmap

English | [中文](roadmap.md)

V2 starts at M7; machine-readable status and dependencies live in [.agents/flow/roadmap.md](../.agents/flow/roadmap.en.md).

## M1 Engineering foundation and quality gates

Deliver FastAPI, Vue 3, the dual-dialect data foundation, OpenAPI, identity, jobs/SSE and CI meta-gates.

## M2 Trace data and normalization

Connect fixtures, local traces, JSONL normalization, agent trees, idempotent replay, query APIs and scheduling.

## M3 Session browsing and execution flow

Deliver the session list, overview, agent execution graph, deep links and performance budgets.

## M4 Problems and attribution

Connect read-only bad cases and probes with problem APIs, cards and error details.

## M5 Evolution loop

Deliver targets, runs, the wizard, six-stage state, events, git candidates and placeholder patch/evaluation.

## M6 Real integration and delivery

Connect real upstream traces, external contracts, patch evaluation and clustering upgrades.

## M7 Identity and workspace boundary

Establish one global admin, workspace roles, the AuthProvider seam, routing and administration.

## M8 Workspace data plane and overview

Connect credential ingest, quota, latest-ten sessions, overview aggregation and drill-down.

## M9 Session evidence and object revisions

Normalize relations, completion, revisions, trigger coordinates and skill, agent or knowledge-document evidence.

## M10 Attribution pipeline and seven-step evolution

Deliver potential matching, attribution cache, candidates, the wizard and seven-step run detail.

## M11 Multi-attribution experience and V2 cutover

Deliver multi-attribution detail, target overview, cross-stack verification and compatibility retirement.

## M12 Real integrations and algorithm delivery

Deliver live upstream data, external contracts, patch/evaluation, clustering, and retained platform-quality debt.
