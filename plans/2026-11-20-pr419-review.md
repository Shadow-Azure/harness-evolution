## 一页速览

**问题**：归因列表只渲染 `object_version`。当它只有 `digest:<sha256>` 时，71 字符版本在窄侧栏不可收缩，把对象名挤成 0 宽，并压住「缓存 / 可归因」标签。

**做法**：有 ref 时显示 ref + 短 commit（与总览一致）；只有 digest 时截断兜底。版本区可收缩、可省略；悬停/聚焦在版本上方显示完整值；旁边的复制按钮复制完整标识。

**代价**：原型定义了一个页面级浮层和一个全局剪贴板动作；生产端需要契约新增 `objectRef` / `objectCommit` 并处理「链接 + 复制按钮」的嵌套交互，不能直接照搬本 PR 的 `div role=button` 结构。

## 架构导览

原型是单文件 HTML，React-like 模板经 htm 渲染。`ErrorApp` 在展开的 bad case 下渲染 `AttributionItem` 等价物；本次把版本展示拆成纯函数 `v2AttrVersionMeta()`，把浮层定位与复制动作拆成 `v2ShowAttrTip()` / `v2HideAttrTip()` / `v2AttrCopy()`：

```text
attribution data (version / objectRef / objectCommit)
        │
        ▼
v2AttrVersionMeta(a) ── ref/commit/digest/missing 分支
        │
        ▼
.ai-obj > .ver-wrap > .ver (ref + commit 或 digest) + .ver-copy
        │ hover/focus                    │ click
        ▼                                ▼
#v2AttrTip (页面级, position:fixed)     v2Copy(完整标识) → #v2Toast
```

浮层放在 `#appShell` 外（`harness-evolution.html:1692`），因为壳层有 `zoom`；放在内部会让 fixed 定位被缩放，实测会压住目标行。

## 数据流走查

1. 原型数据 `attributionsFor()` 产生 `version`；本次另允许 `objectRef` / `objectCommit`（未来生产 API 字段）。
2. `v2AttrVersionMeta()`（`harness-evolution.html:4529`）按优先级：显式 ref/commit → digest → 裸 commit → 从 `EV_TARGETS` 版本表补 ref/commit → 兜底生成 7 位 commit。
3. 模板（`:4693` 起）渲染 `.ver-ref` / `.ver-commit` / `.ver-digest` / `.ver-missing`，并把 `.ver-copy` 放在同一 `.ver-wrap`。
4. 悬停/聚焦调用 `v2ShowAttrTip()`（`:4561`），用 `getBoundingClientRect()` 定位到页面级 `#v2AttrTip`；空间不足时落到下方。
5. 点击复制调用 `v2AttrCopy()`（`:4582`），`stopPropagation()` 防止选中归因项；`v2Copy()` 优先 `navigator.clipboard`，否则 `execCommand` 兜底。
6. CSS `:1436-1447` 用 `max-width:52%/48%` 给对象名和版本区分配空间；`.ver-ref` 固定不收缩、`.ver-digest` 省略，避免再次出现 0 宽对象名。

## 讨论点

### 1. 生产端「链接 + 复制按钮」的嵌套交互

- **位置**：`plans/ui-prototype-v2/harness-evolution.html:4693`
- **现象**：原型用 `div role="button"` 包住归因项，内部又放 `<button class="ver-copy">`；这是原型为了同时支持整行选中和复制。
- **问题**：ARIA 不允许 button 内嵌 button；生产 `AttributionItem.vue` 是 `RouterLink`，直接加复制按钮会出现同样问题，屏幕阅读器也可能把复制读成选中。
- **预判**：原型可接受；生产实现应把复制按钮做成链接的兄弟节点（绝对定位在版本右侧），或用非交互容器 + 独立链接覆盖文本区。结论留维护者。
- **结论**：

### 2. 浮层在窗口缩放/滚动时的位置

- **位置**：`plans/ui-prototype-v2/harness-evolution.html:4561`
- **现象**：浮层只在 `mouseenter/focus` 时计算一次位置；页面壳层有 `zoom`，窗口 resize 会重算 zoom。
- **问题**：浮层显示期间 resize 会短暂错位，直到下一次悬停。
- **预判**：无实害；可在 resize / scroll 时隐藏浮层。结论留维护者。
- **结论**：

### 3. M21 状态修复混在本 PR

- **位置**：`.agents/flow/issues/m21-run-detail-prototype-alignment.md:12`、`.agents/flow/milestones/m21-milestone.md:9`
- **现象**：本地原为 `ready` / `active`，但 GitHub #405 与 milestone #29 已关闭；`flow:sync` 会把它们重新打开。
- **问题**：这是与本功能无关的流程状态修复，混在同 PR 会增加检视面。
- **预判**：状态与远端一致是必要的；若维护者偏好拆分，可单独 cherry-pick 这两个文件。结论留维护者。
