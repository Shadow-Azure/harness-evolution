## 一页速览

一句话：把“生产服务器上安装 Claude Code 并配置 MiniMax 模型”做成发布前的可审计步骤——runner 下载并校验官方 deb，服务器以 `deploy` 用户解包、原子切换软链、原子写 `~/.claude`，密钥只经 stdin 传输。

比喻：runner 是“采购员”，负责按清单买到并验货；服务器是“安装工”，只负责拆包、装到用户目录、把说明书放到 `~/.claude`，不去外网采购。

## 验证基线

- `bash -n deploy/fetch-claude-code-deb.sh`；`python3 -m py_compile deploy/install-claude-code.py`

未验证：生产 `Deploy` 与真实 `claude -p`（需要真实 MiniMax key 与合并后的发布）；本 PR 无 UI 改动，`computer-use-smoke-reporting` 与原型截图不适用。
