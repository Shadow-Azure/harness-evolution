 新版

Claude Code 轨迹原型 →

基于 llm-wiki 4 条真实会话：轮次/步骤模型、React Flow 子 agent 家族树（执行流与触发时序）、真实时间线；家族树的问题卡为打桩，数量对齐会话问题数，列表卡含标题、详情、文件/行号或预期/实际时间；错误详情页按错误查看问题描述与归因分析（结论、分类、定位对象、推导过程）。

 新页

自进化 →

独立于 Session 页面的自进化入口：历史流程 / 正在执行进展查看、按「对象+版本 / 时间段 / 模型多选」筛选问题报告并启动；详情页展示目标基本信息与归因类型分布、聚类结果（来源报告 / 置信度 / 严重程度）、逐轮 edit patch 与评测接纳（commit 携带聚类+报告+现象）、best skill 与初始版本的测试集终评对比。支持「仅聚类分析」与运行中流程的模拟推进。

 #14

Session 浏览器与家族摘要 →

左侧 4 张 root session 家族卡（聚合统计 + 问题密度条）、搜索/状态/排序筛选、选中后的家族摘要落地页、URL hash 状态恢复。右上角可切换「未选中 / 空列表 / 加载失败」三态。

 #15

Turn 时间线核心渲染 →

按 turn 分组 + 吸顶 turn 头（时刻/耗时/事件数/token）；六类事件卡片色彩编码；工具调用与输出用 call_id 徽章配对（点击互相定位）；推理与长输出默认折叠；「仅用户消息与最终回复」快速定位；每卡支持复制 / 原始 JSON。

 实验

家族树 · React Flow →

递归主 / 子 agent 树：条长 ∝ 日志行数，skill 与 subagent 触发点按行号定位；含「嵌套示例」——子任务 C 发现问题、子任务 B 触发 skill，并演示问题卡如何避让兄弟分支。
