# Round 7 UI review

范围：「单个进化对象分析」卡的版式优化，不改信息结构与数据口径。

## 变更项

| # | 问题 | 修复 | 对照 |
|---|---|---|---|
| 1 | 四个统计各占一张卡，行高 40px、留白多，视觉上比卡片标题还抢 | 合并为一条内部分隔的统计条，数字 18px、标签 10px，占一行 | `before-targets.png` → `after-targets.png` |
| 2 | 筛选行直接铺在卡片上，与正文没有层次；时间段贴着版本选择，读起来像一续 | 筛选收进浅底、圆角、细边框的工具条，时间段推到工具条右侧 | `after-targets.png` |
| 3 | 两栏内容之间没有分隔，标题、图例、脚注散布 | 栏间加 1px 分隔线与 22px 内边距；两侧标题与说明统一基线；脚注移到底部横跨两栏 | `after-targets.png` |
| 4 | 每行重复「是 N / 非 N / 未 N」，但没有任何地方给出所选范围的汇总 | 左栏标题右侧放 是 / 非 / 未 汇总图例（颜色点 + 数字），行内保留明细 | `after-targets.png` |
| 5 | 没有数据的版本与有数据的版本一样醒目 | 零数据版本整行降到 60% 透明度，数字位改写字「无潜在 bad case」 | `after-targets.png` |
| 6 | 窄屏时两栏挤在一起 | 1100px 以下改单列，栏间分隔线转为横向分隔，统计条改两列 | `after-narrow.png` |

## 证据

- `before-*.png`：本轮改动前（第 6 轮卡片）。
- `after-*.png`：1440 × 1000 视口，滚动到卡片截图。
- `after-version-menu.png`：版本菜单仍保留最近 5 / 10 / 20 / 全部四档，底部固定。
- `after-narrow.png`：1280 × 960 视口。
