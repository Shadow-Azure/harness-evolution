# Round 10 UI review

范围：关闭弹窗后的焦点回归。

## 修复项

| # | 问题 | 修复 | 对照 |
|---|---|---|---|
| 1 | 第 9 轮把焦点放到「取消」后，关闭确认弹窗时焦点落到页面根节点，键盘用户需要从头 Tab 才能回到原位置 | 打开弹窗时记录触发元素（`V2.modalTrigger`），关闭时若该元素仍在文档中则恢复焦点；动作本身删除了触发元素时自然回退 | `../round9/after-esc.png` → `after-focus-return.png` |

## 验证结果

- 打开「移除成员 王浩」确认弹窗后按 `Esc`：弹窗关闭，焦点回到王浩行的「移除」按钮，截图可见焦点环。
- 再次打开并确认移除：王浩行被删除，触发元素已脱离文档，焦点回退到页面根节点且无报错。
- 「添加成员」弹窗按 `Esc` 关闭后，焦点回到「＋ 添加成员」。
- 浏览器控制台无 error / warn。
- 浏览器视口：默认窗口尺寸（未强制覆盖）。

## 证据

- `after-focus-return.png`：取消后焦点回到「移除」按钮。
- `../round9/after-esc.png`：第 9 轮关闭后焦点丢失的对照。
