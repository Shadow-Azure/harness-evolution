# Round 15 UI review

范围：把「内容区随视口变宽」改成「整体等比放大」——字号、控件、间距一起放大。

## 变更项

| # | 问题 | 修复 | 对照 |
|---|---|---|---|
| 1 | 上一轮只放宽了内容区宽度，字号仍是固定的 12–13px，1700px 窗口下文字与控件相对窗口仍偏小 | 以 1440px 为设计基准，`--ui-zoom = clamp(1, vw / 1440, 1.25)` 写到根元素；`#appShell` 用 `zoom: var(--ui-zoom)` 并把宽度补偿为 `100% / zoom`，内容仍铺满视口 | `before-1700.png` → `after-1700.png` |
| 2 | 放大后依赖视口高度的页面会溢出 | Session、错误详情与 `.v2-page` 的 `100vh` 高度改为 `calc(100vh / zoom - 56px)`，与放大后的顶栏对齐 | `after-session.png` |
| 3 | 顶栏、弹层、Toast 等固定像素组件与内容大小不一致 | zoom 挂在 `#appShell` 上，顶栏、页面、弹层一并缩放；1920px 封顶 1.25× | `after-1920.png`、`after-modal.png` |

## 缩放规则

| 视口宽度 | zoom |
|---|---|
| ≤ 1440 px | 1.00（不放大） |
| 1700 px | 1.17 |
| ≥ 1800 px | 1.25（封顶） |

## 证据

- `before-1700.png`：改动前（`0674dfa`），内容填满但字号仍为原尺寸。
- `after-1700.png` / `after-1920.png`：改动后，同样的 1700 / 1920 视口整体放大。
- `after-session.png` / `after-modal.png`：Session 错误详情与创建空间弹层，验证放大后无溢出、遮罩与居中正常。
