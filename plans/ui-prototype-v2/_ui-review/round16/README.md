# Round 16 UI review

范围：修复大屏下 `#appShell` 只占视口约 80%、内容挤在左上角的问题。

## 变更项

| # | 问题 | 修复 | 对照 |
|---|---|---|---|
| 1 | 2560 / 3440 这类大屏上，整页只占视口约 80%（2560 屏约 2048px），右侧与下方露出 `body` 底色，看起来像内容挤在左上 | `#appShell` 上的 `width: calc(100% / var(--ui-zoom))` 去掉：`zoom` 元素内部的百分比已按缩放坐标解析，再除一次 zoom 会把宽度缩成 1/zoom | `before-admin-2560.png` → `after-admin-2560.png` |

## 根因

`zoom` 元素内的百分比宽度先按缩放坐标解析（2560 视口在 1.25× 下是 2048 布局像素），`100% / 1.25` 得到 1638.4 布局像素，放大后只有 2048 渲染像素——正好是视口的 80%。1440px 及以下 `zoom = 1`，所以看不出问题。

## 实测（修复后）

| 视口 | appShell 覆盖 | 内容区（`.wrap`） | 横向溢出 |
|---|---|---|---|
| 2560 × 1440 | 0 – 2560 | 1720 居中（左右各 420） | 无 |
| 3440 × 1440 | 0 – 3440 | 1720 居中（左右各 860） | 无 |

- `after-overview-2560.png`：总览页同样恢复满宽。
