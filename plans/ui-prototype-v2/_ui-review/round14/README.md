# Round 14 UI review

范围：「查看」状态切换从筛选条移入趋势卡，并重做成带数量的 pill chip。

## 变更项

| # | 问题 | 修复 | 对照 |
|---|---|---|---|
| 1 | 三个状态切换挤在筛选条最右，与时间/粒度/对象混在同一行；趋势卡右上角又重复了一遍同样的图例 | 切换移入趋势卡内、图表说明下方；卡头的重复图例删除，图例由切换项本身承担 | `before-metrics.png` → `after-metrics.png` |
| 2 | 切换项只有名称，看不出各状态有多少 | 每项右侧带该状态在当前筛选范围内的数量（10 / 10 / 11），与顶部统计条口径一致 | `after-metrics.png` |
| 3 | 关闭态与开启态区分弱 | 关闭项整颗降透明度；开启项加蓝边与浅蓝底；hover 蓝边提示可点 | `after-metrics-toggle.png` |

## 说明

- 切换只影响趋势图的堆叠信息，不影响下方「关联 Session / 潜在 bad case / 来源分布」三块汇总（与改动前行为一致），因此标题写作「趋势图显示」。
- 数量取当前时间窗与进化对象筛选下的状态计数，与页头统计条的 10 / 10 / 11 对应。

## 证据

- `before-metrics.png`：改动前（`15b40b5`），「查看」在筛选条右侧，趋势卡头另有图例。
- `after-metrics.png` / `after-metrics-toggle.png`：改动后（1440 × 1000 视口），关闭「非该对象问题」后趋势图只保留绿/灰堆叠。
