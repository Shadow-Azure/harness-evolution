## §6 讨论点

### D1 — HTTP 层遇到非 JSON 错误会泄漏 SyntaxError

- 位置：[http.ts:39](../apps/web/src/api/http.ts:39)
- 现象：`response.json()` 在 status 检查前执行；若网关/后端返回 HTML 或 plain text，抛出的是浏览器 SyntaxError，不是 `ApiError`。
- 问题：公共 `request()` 的契约是“normalize transport failures”，但 malformed-body 这类传输/响应异常未被归一。
- 预判：当前 health 只接受 200/503 且两者均为 JSON，所以无实害；但它是后续所有 API 的共享层，建议在本 PR 加 non-JSON HTTP 500 回归并抛 `HTTP_ERROR`。
- 结论：✅ 2026-10-25 采纳修复；状态检查移到 JSON 解析前，rejected status 返回 `HTTP_ERROR`，accepted malformed body 返回 `INVALID_JSON`，均有单元回归。

### D2 — 样式守卫只扫描 `.vue`

- 位置：[verify-web-style.mjs:24](../scripts/verify-web-style.mjs:24)
- 现象：只读取 `.vue` 文件；新增普通 CSS 文件或 TS 内联 style 中的 literal color 不会被扫描。
- 问题：token-only 目标适用于前端样式面，不只一种文件形态；未来迁移样式到 CSS file 时守卫会自动变弱。
- 预判：当前 `main.css` 和 `tokens.css` 是唯一 CSS，风险低；可留到引入第二个 CSS 文件前扩展，或现在一并扫描受控 CSS。
- 结论：✅ 2026-10-25 延后；不扩大本 shell issue 范围，后续引入第二个受控 CSS 文件前必须扩展扫描器。

### D3 — QueryClient 本身没有直接单元测试

- 位置：[queryClient.ts:7](../apps/web/src/api/queryClient.ts:7)
- 现象：文件覆盖率 0%，聚合覆盖率仍超过阈值；defaults 只由 App 集成行为间接经过。
- 问题：30s staleTime / no retry 是数据层契约，回归时可能被全局聚合掩盖。
- 预判：小型工厂测试成本低，建议补一个直接断言；不阻塞合并，因为集成与覆盖率门禁已真实执行。
- 结论：✅ 2026-10-25 采纳修复；新增 `queryClient.test.ts` 直接钉住 gcTime、retry 和 staleTime。

## §9 文件级代码分析

### `apps/web/src/api/http.ts`

新增共享 fetch 包装。它像前台传达室：网络断线、HTTP 状态错误被换成统一编号的纸条，调用方不需要直接面对浏览器原始异常。`ApiError` 保存 status/code，`request()` 用泛型保留调用侧契约。已知弱点见 D1。

### `apps/web/src/api/health.ts`

新增 health 查询函数。它允许 200 和 503，因为两者都是 FastAPI 的契约化 health 响应；区别由 `db.ok` 在 UI 表达，而不是把“数据库坏了”误报成“前端连不上 API”。

### `apps/web/src/router/index.ts`

新增 Router 工厂。默认页同步导入保证首屏简单稳定，evolution 用动态 import 形成天然边界；`satisfies RouterOptions` 保持路由配置可编译检查。

### `apps/web/src/App.vue`

新增 shell。它把健康状态提升到全局区域，页面只是 RouterView 的可替换内容。状态映射集中处理 pending、error、ok、数据库故障；503 不进 catch，因此不会与网络错误混淆。

### `scripts/verify-bundle.mjs`

新增 manifest 守卫。它像仓库巡检员：从 entry 沿静态 imports 走一遍，任何 Vue Flow 同步闭包都拦下；再沿 dynamicImports 找到 vendor chunk，找不到也拦下。测试覆盖了 Vite preload 字符串只是文件名、不是同步导入的误报场景。

### `scripts/verify-web-style.mjs`

新增 token 颜色守卫。它把 `tokens.css` 当唯一调色盘，扫描 Vue component 中的 hex/rgb 字面量；当前弱点见 D2。

### `.github/workflows/ci.yml`

修改静态 lane。API venv 先创建，再跑门禁自测试，因为 contract workflow 测试会真实调用 Python exporter；随后 web lint/type、覆盖率测试、integration、contract、workspace typecheck、token、build、bundle、docs 和 PR flow diff 按依赖顺序执行。MySQL 和 flow-online 保持独立 lane。
