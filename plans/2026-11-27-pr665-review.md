## §3 数据流走查

1. 管理员编辑目标：表单回显 `targetMembers()` 的 `matchByName`（缺省 false）→ 提交 `EvolutionTargetWrite.members[]`。
2. API 校验：`_normalize_member` 保留 skill/agent 布尔值，knowledge 置 false；`_prepare_write` 交给 repository。
3. 持久化：`update` 比较包含开关的成员签名；变化时刷新绑定批次；成员行写入 `match_by_name`。
4. 总览：`_analyse_config` 逐成员窄化；开启成员走 `_name_matched_version`，关闭成员走 `_build_version_labels`；两者合并为一条配置行。
5. 启动：`_match_condition` 与 `_run_values.targets` 带开关；run 快照冻结。
6. 准备/绑定：`prepare._condition` 与 `BindingWorker` 从快照/成员带开关；matcher 对开启成员忽略版本过滤，对关闭成员保持 body hash 过滤。
7. 报告：仍按 `targetRevision` 与缓存键，不因开关改变。

## §6 讨论点

### D1 绑定快照的一次性归一化

- **位置**：`apps/api/app/service/evolution/binding_worker.py:126`
- **现象**：旧 `attribution_snapshot.members[]` 没有 `match_by_name`；升级后首次 tick 会补写 false，并触发一次快照比较差异。
- **问题**：会不会重复归因或改写历史报告？
- **预判**：不会。`attribution_generation` 不变，报告按 generation/case 去重；只是一次性快照字段归一化。若想消除写入，可在 false 时省略该键。
- **结论**：

### D2 预览条件仍只带首个成员

- **位置**：`apps/api/app/service/evolution/potential.py` 的 `PotentialPreviewService._condition`
- **现象**：向导预览的 `MatchCondition` 仍不填 `targets`，matcher 合成首个成员；launch/prepare/binding 已带成员级 targets。
- **问题**：这是否与 issue“MatchCondition 始终携带成员级 targets”矛盾？
- **预判**：预览当前不传 revision 过滤，开关不影响其默认 presence 行为；issue 也明确不改变向导默认口径。真正要统一多成员预览时另开 issue，避免在本 PR 扩大行为面。
- **结论**：

### D3 MySQL 迁移未在本地实跑

- **位置**：`apps/api/alembic/versions/0037_member_match_by_name.py:31`
- **现象**：本地只对 SQLite 迁移路径与 repository 做了实测；MySQL 依赖 CI 的 db lane。
- **问题**：`op.add_column` + `sa.false()` 在 MySQL 上是否安全？
- **预判**：`Boolean NOT NULL DEFAULT 0` 是 MySQL 支持的 DDL；无回填、无长事务。风险主要在 CI 未覆盖的旧 MySQL 版本，需看 CI 结果。
- **结论**：

### D4 文字标签的点击行为

- **位置**：`apps/web/src/pages/evolution/targets/components/TargetFormDialog.vue:706`
- **现象**：首版只有开关本体可点，原型里文字标签也可点。
- **问题**：是否算 UI 差异？
- **预判**：算轻微交互差异；本 PR 已把外层标签加 click 切换、开关区 `@click.stop`，并补单测。
- **结论**：

### D5 run 卡片顶层 `matchByName` 的兼容投影

- **位置**：`apps/api/app/service/evolution/runs.py`
- **现象**：`EvolutionRunCard.target` 的开关取 `run.targets[0]`，多成员时顶层只代表首个成员。
- **问题**：是否误导？
- **预判**：顶层字段本就是首个成员的兼容投影；完整信息在 `targets[]`。前端目前不展示该字段，保持兼容即可。
- **结论**：
