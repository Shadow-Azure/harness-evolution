# m6-16 原型修改：数据同步浮层四段化

## 修改点

- 顶栏“数据同步”浮层重排为四段，顺序固定：**问题数量 → 问题轨迹 → 会话归一化 → 归因分析**。
- **问题数量**：bad_cases 目录同步，显示 `总 136 · 已同步 128 · 未同步 8`；子行显示“空闲 · 游标 #128”。实现态会映射为同步中 / 同步失败（稳定文案）/ 未配置坏例查询服务。
- **问题轨迹**：沿用 m6-15 的根会话轨迹统计，子行保留“同步中 1 · 失败 2”。
- **会话归一化**：沿用 acquisition 的待处理 / 已处理 / 已导入。
- **归因分析**：只读 `bad_case_analysis` 的整体进度，显示 `已分析 96 · 待分析 40`，子行“问题 58 · 非问题 38”；不实现归因流程。
- 新增 `.tn-sync-sub + .tn-sync-row` 分隔线，让“状态子行 → 下一段”也有清晰分组；浮层宽度、字号、颜色 token 与移动端断点均未变。
- `<summary>` 的 `aria-label` 扩展为四段统计；摘要胶囊的“问题轨迹 7/12”徽标保持不变，避免顶栏拥挤。
- 未新增页面、按钮或手动触发入口。
