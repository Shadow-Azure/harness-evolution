# m6-15 原型修改：问题轨迹同步统计

## 修改点

- 顶栏右侧新增“数据同步”胶囊：显示待处理数，并用 `问题轨迹 已同步/总数` 作为二级摘要。
- 点击胶囊展开浮层：
  - `会话归一化`：待处理 / 已处理 / 已导入（沿用现有 acquisition 语义）。
  - `问题轨迹`：总根会话 / 已同步 / 未同步，并补充同步中 / 失败数。
- 该浮层只读展示，不新增手动触发按钮；自动补齐由定时任务负责。
- `≤1100px` 隐藏数据同步胶囊，与应用现有 `TopNav` 的 `.sync-status` 行为一致；移动端不新增横向溢出。
