P1

Round 可引用其他 run 的 cluster

Actual
独立 FK 只保证 cluster/run 各自存在，不保证二者属于同一 run；cluster 删除会通过 CASCADE 误删外来 round。
Expected
insert_rounds 在同一事务内批量校验所有 cluster 属于 round.run_id；缺失或跨 run 一律 409 且不写入。
Root cause
数据库缺少组合外键，repository 未补跨表不变量。
Regression
跨 run 与不存在 cluster 均有回归；失败后 rounds 为空、其他 run 数据不变。
