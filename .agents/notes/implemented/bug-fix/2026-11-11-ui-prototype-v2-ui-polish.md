# Agent Note: V2 原型 UI 可读性与交互修正

Status: implemented

[English](2026-11-11-ui-prototype-v2-ui-polish.en.md) | 中文

## Problem

V2 原型在真实浏览器里暴露出几个会误导评审的可见问题：顶栏四个入口在 1408px 下从词中间折行；家族树把普通滚轮当成缩放，用户想向下看列表却把图缩到不可读；`--text-faint` 用于图表刻度和表格辅助信息，对比度只有约 2.6:1；Session 壳层按 100px 偏移计算高度，在隐藏子页签后留下 44px 空带；长会话 ID 把详情操作按钮挤到第二行；来源汇总第三列与进化对象侧卡分页也没有对齐卡片边界。

第三轮又发现状态与内容不自洽：已完成运行的拒绝轮次仍显示正向分差，测试集终评副标题保留字面量「M 轮」，问题复现率上升被着色为收益；添加成员默认授予空间管理员；空间管理列表页底部留出大块空白；1280px 下 Session 统计条末项折行。

第四轮发现默认策略在运行详情与向导里混用 `+` 与 `∪`，前者容易被读成加分或叠加；向导第 3 步内容超出 `66vh` 时依赖 macOS 的 overlay 滚动条，读者看不到可滚动提示；登录页第三条说明产生「话。」孤行；鉴权接入说明混用英文 `membership`；自定义策略说明写成「在默认策略上叠加规则」，与勾选规则重新组合的实现不符。

第五轮发现登录页页脚把「SSO/OIDC 回调」拆成单字「调」，且说明称其余账号演示只读成员，但登录账号列表刻意排除了唯一的只读成员王浩；成员页同时写「拥有全部操作权限」与「只能授予管理员以下」，也没有说明只有全局管理员能任命空间管理员；聚类来源表、向导表头与策略开关仍直接暴露 `object_name` 字段名。

第六轮发现进化对象配置弹窗只有验证集与测试集两个字段标了必填，但保存时对象名称、仓库地址、子目录与基线也会校验；同时第四轮把登录页「视觉与交互基线」指向了当前文件自身，形成自引用。

第七轮发现 `ws-harness` 在空间管理里创建于 2026-09-12，但该空间最早 Session 是 2026-08-23，总览 8 月已有 bad case；用户菜单的演示身份把李伟、陈雨等空间管理员标成「普通用户」，与登录卡片和页头的「空间管理员」不一致。

第八轮发现三处危险操作点击即生效：移除成员会立即删除成员，重新生成凭据会让旧凭据立即失效，移除进化对象会立即改变统计、趋势与启动向导；三者都没有确认步骤，误点无法撤销。

第九轮发现第八轮的确认弹窗只能用鼠标取消：`Esc` 只关闭菜单，弹窗内按 `Esc` 没有反应；打开后焦点仍留在触发按钮，键盘用户需要从头 Tab，且弹窗缺少对话框语义。

第十轮发现第九轮把焦点移到「取消」后，关闭弹窗会把焦点丢到页面根节点：取消一次危险操作，键盘用户就得从页首重新 Tab 回原位置。

## Decision

在同一份 `plans/ui-prototype-v2/harness-evolution.html` 内做最小修正：顶栏入口不可收缩并保持单行，1400px 以下隐藏副标题；两个 React Flow 实例关闭滚轮缩放、允许页面滚动，`minZoom` 提到 0.5；`--text-faint` 改为 `#66707c` 并提高刻度和汇总数字字号；Session 壳层改为 `calc(100vh - 56px)`，详情头首列可收缩并省略超长 ID；来源汇总列扩到 120px；进化对象侧卡改为纵向 flex，分页贴底。每轮修复前后的截图保存在 `plans/ui-prototype-v2/_ui-review/`。

第二轮继续修交互状态：页面与工作空间写入 URL，浮层统一由外部点击/Esc/切页关闭；家族树画布在短视口自适应并把图例移入普通文档流；错误详情执行流在短视口压缩以露出问题详情；切换工作空间时关闭旧空间错误详情并刷新新空间 Session；时间线只对有真实数据的 Session 渲染，其余显示带正确标题的空态。

第三轮把拒绝轮次的候选分改成低于 current，终评副标题使用实际轮数，`evDelta` 增加 `lowerBetter` 方向；添加成员默认角色改为成员；空间管理内容卡最小高度收到 340px；运行卡百分比标注为「总进度」；Session 统计标签禁止换行并收紧内边距。

第四轮把默认策略统一为「对象自身 self 上报 或 触发点在对象触发点之后」，并给弹窗正文加 10px 常驻滚动条；登录页第三条说明显式分成两行；鉴权说明统一使用「成员关系」；自定义策略说明改为「勾选规则组合成策略」。

第五轮把登录页脚拆成「Cookie 会话 / 用户信息映射」与「SSO/OIDC 回调 / 接入说明」两行，只读成员说明改为登录后在用户菜单切换；成员页说明改为空间管理员可管理成员、额度与上报凭据，但只能授予成员或只读成员；用户表格与策略开关统一使用「对象」「仅纳入同对象」，接入契约示例继续保留 `object_name`。

第六轮给对象名称、仓库地址、子目录与基线分支/标签补上必填标记，并把登录页基线路径恢复为 V1 原型 `plans/14-15-ui-prototype/harness-evolution.html`。

第七轮把 `ws-harness` 创建时间改为 2026-08-01，早于最早 Session；新增 `v2UserRoleBadgeLabel` 统一登录页与用户菜单的显示角色，空间管理员在所有入口都显示为「空间管理员」，普通成员显示为「普通成员」。

第八轮新增通用 `v2Confirm(title, desc, action)` 弹窗，把待执行动作暂存在 `V2.pendingConfirm`，确认后才调用，取消、点背景或关闭都会清空；三处危险操作各自写明后果，确认按钮使用危险色。确认与取消按钮补进文档级点击选择器，避免弹窗可见但点击无响应。

第九轮让 `Esc` 优先关闭已打开的弹窗：`v2CloseModal` 同时清空 `V2.pendingConfirm`，因此关闭即跳过待执行动作；没有弹窗时仍走菜单关闭。`v2Confirm` 打开后把焦点放到「取消」，让 `Enter` 的默认结果是取消而不是确认；弹窗补 `role="dialog"`、`aria-modal="true"`、`aria-labelledby`，关闭按钮补 `aria-label`。

第十轮在 `v2Modal` 打开第一个弹窗时记录 `document.activeElement` 到 `V2.modalTrigger`，`v2CloseModal` 清空弹窗后若该元素仍在文档中则恢复焦点；确认动作把触发按钮随行删除时，`isConnected` 检查让焦点自然回退，不会抛错。

## Alternatives considered

- 直接修改生产 `apps/web`：会把原型评审与产品实现混在一个 PR，且当前 issue 只覆盖原型资产。
- 只在 1100px 以下隐藏副标题：1408px 下仍然折行，问题没有被解决。
- 保留滚轮缩放并把图例移到固定浮层：手势冲突仍在，用户依旧会误缩放。
- 只加深颜色不改字号：低对比度缓解了，但 9px 日期在密集周轴上仍难读。
- 保留 `+`/`∪` 作为数学记号：`+` 在进度与收益语境里会读成相加，`∪` 又依赖字体支持；统一用自然语言「或」更不容易误读。
- 依赖系统 overlay 滚动条：macOS 默认不显示滚动条，短视口下读者无法判断弹窗正文还有内容。
- 把王浩加入登录账号列表：会多出一张账号卡，1408 × 611 下登录按钮与页脚会被挤出首屏；用户菜单已能切换身份，改说明成本更低。
- 保留 `object_name` 作为字段对照：表头其余列已是自然语言，混用字段名破坏表格可读性；API 示例仍保留字段名。
- 只标注验证集/测试集两个必填项：保存逻辑同时要求对象名称、仓库、子目录与基线，标记与实际校验不一致会让读者反复试错。
- 保留自引用的基线路径：读者无法判断「基线」指哪一版原型；V1 文件仍在仓库中，恢复旧路径语义更准确。
- 把 8 月 Session 的 workspace 改到其他空间：会连带改变总览计数、bad case 归属与额度使用，改创建时间影响面更小。
- 在用户菜单保留全局角色并注明「全局普通用户」：仍与页头的空间角色冲突，读者需要自己换算。
- 让危险操作直接执行：误点会立即删成员或使凭据失效，原型评审也无法演示「可撤销」这一层交互。
- 使用原生 `confirm()`：阻塞式弹窗的视觉与原型其余弹窗不一致，也无法写清「已有记录保留」这类后果说明。
- 只在确认弹窗上挂 `keydown`：其它表单弹窗仍然不能用 `Esc` 关闭，行为分裂；统一在文档级接管更一致。
- 打开后不移动焦点：键盘用户按 `Enter` 可能落到确认按钮，反而更容易误删。
- 关闭后统一把焦点放到页面主标题：位置稳定但不回到用户刚才操作的行，重复取消时仍要重新定位。

## Consequences

原型与生产前端的样式差异继续扩大，后续对齐时需要以本文件和截图为准。审阅截图会增加仓库体积，但能让人快速复核每轮判断。导航阈值 1400px、树图最小缩放 0.5、画布高度 clamp 都是经验值，若后续接入真实数据导致标签或节点变多，需要重新测量。URL 目前用 `replaceState`，刷新能恢复当前页面与空间；浏览器后退仍会离开原型，若需要完整 history 语义需另做 `pushState` 与 `popstate` 回放。 滚动条样式使用 `::-webkit-scrollbar`，Chrome 与 Safari 会常显；Firefox 仍回落为原生滚动条，若后续扩大浏览器支持需补 `scrollbar-color`。 登录页的只读成员说明依赖用户菜单里的身份切换，若以后移除该入口需要同步改文案。 基线路径再次指向 V1，若 V1 目录迁移需要同步更新；必填标记需与 `evSaveTarget` 的校验列表一起维护。 `ws-harness` 的创建时间早于成员加入时间（2026-09-12），表示空间先建立、成员后加入；角色标签按最高空间角色计算，同一用户是多个空间的管理员时菜单只显示「空间管理员」而不区分空间。 确认弹窗把回调存在全局 `V2.pendingConfirm`，同一时刻只允许一个待确认动作；以后新增危险操作应复用 `v2Confirm` 而不是直接改状态。 现在所有弹窗都响应 `Esc`，表单里未保存的输入会被直接丢弃；若后续需要「有未保存改动时二次确认」，要在 `v2CloseModal` 之前加脏检查。 焦点回归依赖触发元素仍在文档中；若后续把弹窗改成先销毁再重建列表，需要在重建后手动把焦点还给对应行。
