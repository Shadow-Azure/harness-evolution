# Agent Note: 自进化检查点暂停

Status: implemented

[English](2026-11-20-evolution-pause-resume.en.md) | 中文

## Problem

自进化启动后缺少用户可恢复的暂停；异常中断会留下不确定副作用，且不等价于暂停。

## Decision

将用户控制与执行阶段分开持久化，先记录暂停意图，在安全检查点保存产物并释放 worker；继续复用原 run、commit 与外部评测 ID。已提交评测可继续运行，只收集结果而不推进。初始运行与任务同事务写入，认领与暂停统一按运行行加锁。暂停与失败交错时保留阻塞原因并关闭自动重试；无法证明冻结输入的历史运行明确失败，不重读可变输入。恢复依据工作区发布和每簇轮次的持久化事实选择阶段，保留已完成评测与已落库决定；本地候选回放恢复选中分支和冻结的推送目标，避免重复副作用。

## Alternatives considered

仅每轮末尾暂停等待过长；强杀协程/进程可能产生半成品和未知推送；把暂停复用为 blocked 会与自动重试混淆；在 handler 内等待会占住串行 worker。

## Consequences

需要统一所有调度入口、条件写入、重启恢复、评测超时和工作区保留策略。暂停不承诺立即停止外部计算，也不允许改变冻结输入。

浏览器回归的协议请求和HTTP等待必须有截止时间；断连应结束待处理请求并释放资源，避免验收无限等待。阶段日志用于定位超时边界，不替代业务断言。正常过程截图仅在显式保留产物时采集，失败诊断仍有界执行；业务验收不依赖生成后即删除、没有图像断言的截图副作用。
