# Agent Note: 空间归因 Skill 交互原型

Status: implemented

[English](2026-11-19-attribution-skill-prototype.en.md) | 中文

## Problem

空间归因 Skill 包有独立的上传和启用动作。仅凭设计文字难以检查列表状态和当前提示词是否同步，也容易忽略管理员与只读角色的操作差异。

## Decision

在 V2 原型已有的空间管理页面中展示包管理。演示 ZIP 与列表和提示词使用同一组样例数据，操作状态按工作空间保存在内存中。只读深链让评审者可以复核下载权限和写入口的可见性。

资源库沿用空间管理页签的紧凑表格与按钮，详情区采用上报接入的内嵌代码预览。列表和详情处在一个页签中，管理员和只读成员能在同一位置查看所选包。

## Alternatives considered

静态页面无法复核启用、删除和默认回退的状态变化。接入真实包管理 API 和通用 ZIP 校验会把服务端契约引入交互原型，增加验证交互所需的环境依赖。

给资源列表另设外框会重复空间管理内容区的边界，也会把列表的字号和操作密度与相邻页签分开。

## Consequences

页面可以独立复现上传、启用、删除回退与只读路径。示例 ZIP 可在本地下载并重新选入，刷新恢复初始数据。
